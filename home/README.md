# Portable home policy

Files here are inventory copies of source configuration. The installer deploys
only explicit areas in `manifests/deployment.toml`; the shell and Hyprland
snapshots are quarantined pending compatibility/layout review. No live files
were linked or deployed during Phase 2 development. `hosts/` owns monitor/output,
hardware environment and other machine-bound configuration; profile selection
never depends on hostname.

Omitted from this tree: browser profiles, credentials, agent state, generated
Omarchy state, plugin checkouts, and `hypr/monitors.conf`.
